# Roadmap: the next two projects

Two home-lab projects follow LabOps and the [Linux Platform](https://github.com/muhammadbilaljaved684-dotcom/Linux-Platform). Both use the same fictional company, Northwind, and the same 15 users, so the Microsoft 365 project can connect to the Active Directory from the Windows project.

| Project | What it covers | Status |
|---|---|---|
| [Windows Admin](windows-admin/README.md) | Active Directory, DNS, DHCP, Group Policy, file services, disaster recovery drills | Planned |
| [Microsoft 365](microsoft-365/README.md) | Entra ID, Conditional Access, Intune, Exchange Online, Teams, Defender, Purview, hybrid identity | Planned, after Windows Admin |

The diagrams show the design I am building towards. Results, screenshots and recovery times will be added as each phase is done.
